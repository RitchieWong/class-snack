# 上课偷吃

一个微信小游戏原型。坐在教室里，趁老师背身偷吃薯片：按住送进嘴，继续按是快嚼，松手立刻收手并改成慢嚼。

这一节是 45 秒数学课，目标吃下 5 口。老师停笔转肩后会回头，手还举着就会被记名；中途老师会从左侧走到桌边，嘴里还有东西也会被抓。第一次记名，第二次没收零食。

## 本地试玩

1. 打开微信开发者工具。
2. 导入本目录，项目类型选择「小游戏」。
3. 可使用游客模式或替换 `project.config.json` 里的 AppID。

操作：按住屏幕偷吃，松开收手。结算后点「再上一节」。
