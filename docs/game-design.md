## 1. 项目定位

**一句话玩法：** 坐在教室里偷吃零食。趁老师背身拿一口，借齐读快嚼，赶在下课铃前全部咽下去。

**想做出来的感觉：** 老师回头了，手藏得住，嘴里那口怎么办？玩家盯着老师的动作做判断，在「现在吃得更快」和「收手等一下」之间选择。危险解除后，嚼完、咽下的那一下要让人松口气。

**设计原则：**

- **一根手指能玩。** 主要动作是按住和松手；四向查看服务于判断，第一关不要求频繁切镜头。
- **老师的规则能学会。** 板书和巡逻的时间可以变，停笔、转肩、脚步、后门影子等征兆保持一致。
- **每堂课考不同的判断。** 数学课读动作，语文课借声音，自习课要提前处理嘴里那口和桌上的痕迹。

## 2. 玩法设计

### 2.1 一局流程

进入课堂 → 观察机会 → 拿一口 → 快嚼或慢嚼 → 咽下计数 → 吃够目标或铃响 → 结算 / 再来一局。

- 达到目标口数即通关；铃响时没吃够，按实际咽下的口数结算。
- 第一次被抓：记名，当前这口作废，可以继续拿；已经咽下的保留。食物袋仍能补拿，抓一次后还有机会通关。
- 第二次被抓：零食被没收，提前结算。
- 结算显示吃完口数、抓包次数与具体原因，如「老师走到左侧时，你还在嚼」。

### 2.2 玩家操作

| 操作 | 发生什么 | 玩家要判断什么 |
| --- | --- | --- |
| 按住桌洞里的零食 | 手拿起一口送入口；入口前松手会放回 | 能不能在老师转身前完成送入口 |
| 入口后继续按 | 快嚼，进度走得快，声音更大 | 现在的课堂声音能不能盖住咀嚼 |
| 松手 | 双手立即回到桌上；已经入口的进度保留，切换为慢嚼 | 这时藏手是否足够，老师会不会走近检查 |
| 咀嚼完成 | 自动咽下，计一口 | 下一口要不要马上开始 |
| 左右滑 / 点后门提示 | 瞟同桌、过道或身后；切视角不改变真实危险 | 危险来自哪个方向，是否还有行动窗口 |

**原型默认：** 一次长按只吃一口，吃完后松开再按才拿下一口。是否支持自动续吃，等试玩后决定。

### 2.3 危险和预警

| 危险 | 先给什么信号 | 什么情况下抓包 | 能做什么 |
| --- | --- | --- | --- |
| 讲台扫视 | 粉笔停顿，老师先转肩 | 老师看向本排时，仍在举手送食物 | 松手收手，继续慢嚼 |
| 安静时的声音 | 齐读收尾，或老师侧耳；界面同步给信号 | 安静后仍持续发出明显的咀嚼或包装声 | 慢嚼，等下一次声音掩护 |
| 过道近查 | 脚步、影子和对应方向图标靠近 | 老师走到桌边时仍鼓着腮帮，或桌上留着包装 | 提前咽下，把东西收回桌洞 |
| 后门突检 | 门缝有影子或门把响，后方提示出现 | 主任从后面看到玩家拿着零食 | 收手，确认前后都安全再拿 |

数学课的节奏：**背身板书 → 停笔转肩 → 回头扫视 → 继续板书**。前几关每次重点考一种危险；后面可以叠加，但要有至少一种来得及采取的应对。

### 2.4 随机与计分

- **练习局随机：** 板书时长、巡逻路线、道具。预警方式与抓包条件固定。关卡要留足可过关的机会，避免一开局就注定吃不完。
- **榜单局固定：** 同一题的老师事件、食物与道具一致。玩家可以反复挑战、练熟节奏。
- **基础计分：** 每咽一口 +100 分，零抓包通关额外 +100 分，每次抓包 −50 分，最低 0 分。同分且都通关时比用时，其余同分并列。

### 2.5 原型参数（暂定）

| 参数 | 初值 | 调整时看什么 |
| --- | --- | --- |
| 每局时长 / 通关目标 | 45 秒 / 5 口 | 新手理解规则后，还有没有机会吃完 |
| 拿起至入口 | 约 0.6 秒 | 玩家松手时能否看懂食物有没有入口 |
| 一整口快嚼 / 慢嚼 | 约 1.5 秒 / 3 秒 | 快嚼值得冒险，慢嚼也有用 |
| 数学老师背身板书 | 3–6 秒 | 每个窗口能吃几口，有没有抢下一口的犹豫 |
| 停笔转肩 / 回头扫视 | 约 1 秒 / 约 2 秒 | 玩家能看见预警、及时收手，扫视期间不用等太久 |
| 抓包上限 | 第 2 次结束 | 第一次失误后是否还愿意继续玩 |

### 2.6 紧张和爽感：做出「差一点被抓」的一口

> **优先验证。** 玩家的紧张来自「我知道老师要来了，但这口还没咽」；爽感来自「我自己做了判断，刚好躲过去」。危险由老师真的做了什么决定，不能只靠屏幕变红、心跳变快。

#### 一次完整的惊险过程

| 时刻 | 玩家看见或听见什么 | 玩家能做什么 |
| --- | --- | --- |
| **机会出现** | 老师背身写题，视线离开这排 | 按住，把薯片送进嘴。玩家自己决定要不要吃下一口 |
| **危险逼近** | 粉笔停、肩膀动；换成巡逻时，则是脚步和桌面影子越来越近 | 讲台扫视就松手藏动作；老师要走到桌边时，提前咽下比藏手有用 |
| **最后一个选择** | 嘴里还有三分之一，老师还有一步到桌边 | 敢不敢再按半秒快嚼？来得及就咽下、收手；判断来不及时，应该在上一拍就放弃起手 |
| **擦肩过去** | 老师的视线从你身上移开，或脚步从桌边走远 | 「咕咚」响、口数跳一下之后，紧接着老师从桌边走过去，紧张才彻底解除 |

**原型示例：** 按现有初值，嘴里已经嚼到约 65% 时，快嚼还要约 0.53 秒，慢嚼还要约 1.05 秒。老师还有约 0.8 秒走到桌边，这时两种操作会产生不同结果。这个检查点只在近处看嘴里还有没有东西，途中不再叠加听声抓包。画面用「脚步到了上一张桌」「影子扫过试卷」表达距离，不要求玩家盯小数。玩家也可以在脚步刚响时就先吃完，稳稳通过。

#### 把反馈落在教室里

- **吃到嘴里就有反馈。** 包装轻响、手带着薯片抬起、咔嚓声和咀嚼进度一起走。吞咽给一声短「咕咚」和一格计数变化，普通一口也要吃得有手感。
- **老师来的时候，先动老师。** 停笔、眼镜上方瞟一眼、鞋尖进入过道、影子划过卷面，都是实际危险的信号。图标同步补方向；静音时也能判断。不要用全屏闪红盖住老师动作。
- **松手装乖要快。** 手立即收回桌上，嘴里的进度仍然显示。让玩家看到「手安全了，嘴还没安全」，不用读文字才知道发生什么。
- **危险走过去，玩家才松口气。** 脚步远离、老师回头继续写、粉笔声恢复。只有确实在视线或检查到来前解决了风险，才偶尔给一句「好险」；不加分，避免玩家专门卡时间刷惊险。
- **被抓也要像一幕喜剧。** 老师停在桌边：「你嘴里嚼什么呢？」粉笔点一下桌角，结算指明是「手没收回」还是「到桌边还没咽」。玩家应知道下次能怎么救。

#### 一局的起伏

先给一次宽窗口，让新手吃到第一口；中段安排两三次不同长短的机会，让人犹豫要不要再拿；熟悉之后加入一次有明确预告的近查。最后几秒保持一个可争取的窗口，提前吃完照常通关，不把每局都卡成最后一秒。

按当前数值，五口全程慢嚼的理论净时间约 18 秒。数学课如果只查举手，可能每次看老师背身拿一口就稳过。这可以做教学局；正式关先验证**一次近查是否真的改变玩家行为**，再决定要不要压缩窗口。

## 4. 课堂、角色与道具

### 4.1 课堂与老师

| 课堂 | 对手 | 本关新增的判断 | 阶段 |
| --- | --- | --- | --- |
| 数学课 | 任课老师 | 读停笔和转肩，学会松手收手 | 原型 |
| 语文课 | 领读老师 | 借齐读快嚼，停读后压低声音 | 试玩 |
| 自习课 | 班主任 | 读脚步和距离，提前咽下、收桌面 | 后续 |
| 突击检查 | 教导主任 | 盯后门，正面安全时也要留意身后 | 后续 |
| 公开课 | 校长 | 分段组合扫视、巡逻和后门检查 | 后续 |

**老师的处罚演出：** 粉笔头落桌用来表现抓包；扣分进结算；后续可以让老师抽走用来挡脸的课本，短时间失去遮挡。「记过」「开除」可用作高难关的搞笑退场字幕，只影响当局。

### 4.2 零食与道具

| 内容 | 玩法作用 | 阶段 |
| --- | --- | --- |
| 薯片 | 咽得快、咔嚓声大；原型用它验证快慢嚼 | 原型 |
| 软糖 | 安静、嚼得久；被巡逻逼近时更难及时咽下 | 试玩 |
| 饼干 | 容易掉渣，给桌面检查增加一种痕迹 | 后续 |
| 翻页声 | 一次性声音掩护，可以盖住一口咀嚼声 | 后续 |
| 立起来的课本 | 临时遮挡部分视线，有可能被老师抽走 | 后续 |

## 5. 视觉与交互

### 5.1 画风

- **真实在物件：** 木桌划痕、卷角试卷、笔袋拉链、起皱的包装、擦不净的黑板。
- **可爱在造型：** 老师和同桌有好辨认的轮廓和表情，桌面文具颜色轻松，零食一眼能认出。
- **夸张在动作：** 手一下缩回、头像腮帮鼓起来、老师捏着粉笔转肩、粉笔头落到桌角弹两下。

### 5.2 镜头与信息

竖屏第一人称，玩家坐在固定座位。下半屏是双手、桌面和桌洞，拇指在这里操作；上半屏是老师、讲台和课堂动静。正面看讲台，左右看同桌和过道，向后看后门。原型先做正面；试玩再加一个侧视角。

| 信息 | 表现方式 |
| --- | --- |
| 还剩多少时间、吃了几口 | 屏幕顶部常驻，铃响前再强调 |
| 这一口有没有入口 | 手部动画与嘴里进度同步；收手之后，进度仍然可见 |
| 危险来自哪里 | 对应边缘显示图标和方向，颜色辅助区分 |
| 为什么被抓 | 当场给短动作反馈，结算写明触发原因 |

**首批素材清单：** 教室正面、课桌和桌洞、试卷与笔袋、薯片包装、手部四个关键动作（拿起 / 送入口 / 收回 / 放桌上）、老师四个关键动作（板书 / 停笔 / 转肩 / 扫视）。[概念图和四向视角示意见配图稿](./design-preview.html)。

## 6. 声音与反馈

| 场景 | 听到什么 | 静音时看到什么 |
| --- | --- | --- |
| 老师准备回头 | 粉笔声停一下 | 粉笔停住、转肩、顶部预警 |
| 全班齐读 | 齐读声盖住包装和咀嚓 | 「齐读中」提示，结束前有变化 |
| 过道或后门来人 | 脚步由远到近，或门把响 | 影子、对应方向图标 |
| 成功咽下一口 / 被抓 | 短促吞咽声 / 粉笔敲桌声 | 口数跳动 / 老师动作与抓包原因 |

原型优先做粉笔、包装、快嚼、咽下和下课铃。振动是可关闭的辅助反馈。课堂环境声要给危险信号留空间。

## 7. 成长与收藏

- **课表：** 通过前一堂课解锁下一堂，每次解锁对应一种新判断。
- **桌洞收藏册：** 用课堂通关和特殊表现解锁零食、桌贴、笔袋和称号。零食带来不同取舍，周榜统一配置。
- **称号举例：** 「铃响前一口」在最后一秒完成目标；「桌洞清洁工」通过巡逻关且没被查到包装。称号随玩家保留，不随周榜清分。

## 8. 好友与榜单

**先做异步的「同一堂课」。** 每周一套固定挑战，每人取本周最好成绩。换周换题，榜单重新排名，个人历史最佳、收藏与称号保留。

- 结算可主动分享同题卡。示例：「我在下课铃前 0.3 秒咽下最后一口，来试试？」好友点开进同一题。
- 个人练习可使用自选食物与道具；榜单只记录固定配置的挑战成绩。
- 实时同桌合作暂作后续探索。接入参考：[微信同玩好友榜示例](https://wechat-miniprogram.github.io/minigame-canvas-engine/demos/rank.html) · [微信分享卡参数](https://github.com/wechat-miniprogram/minigame-api-typings/blob/master/types/wx/lib.wx.api.d.ts#L7547-L7569)。

## 9. 版本范围与试玩

| 阶段 | 做什么 | 达到什么效果再往下做 |
| --- | --- | --- |
| 最小原型 | 一张桌子、一堂数学课、一包薯片；正面视角、快慢嚼、转肩预警、抓包和重开 | 玩家会主动松手，知道为什么被抓，愿意自己再来一局 |
| 微信试玩版 | 加语文课、软糖、侧视角、静音提示和个人最佳 | 换课之后会主动借齐读快嚼，静音时也能判断危险 |
| 内容与社交 | 加巡逻、后门、四向视角、收藏册、好友周榜和挑战卡 | 玩家愿意学新课堂、刷自己的最好成绩或接好友挑战 |

**第一轮怎么测：** 找 8–12 人试玩，开场只说「按住吃，松手藏」。观察第一次收手是在老师转身前还是之后、玩家能否说出抓包原因，以及结算后是否主动重开。如果大家只在老师背身时一直按住，优先调窗口长短与快慢嚼的收益。

## 10. 待补与待验证

- [ ] **玩法：** 原型试一次一口，观察松开再按是否打断节奏；必要时对比自动续口。
- [ ] **交互：** 测试切视角时是否容易误触偷吃，确定按住期间切视角的处理方式。
- [ ] **课堂：** 设计桌面收拾动作与饼干掉渣规则；验证后门与讲台危险叠加时仍可应对。
- [ ] **视觉与声音：** 确定老师造型，验证转肩动作、左右方向和齐读结束在静音下都能读懂。
- [ ] **竞赛：** 定切后台、异常退出和换周时间；确认成绩提交与好友卡进入同题的细节。

## 11. 核心玩法候选

> 以下是可选玩法，逐个试玩。主操作保留「按住吃、松手藏」。一堂课先只加一种主要判断。

| 候选 | 这一刻玩家在赌什么 | 建议怎么用 |
| --- | --- | --- |
| **近查清嘴** | 手已经藏了，老师还差一步。再快嚼半秒能吞，松手慢嚼可能来不及 | **第一优先。** 复用长按，做一次真实的擦肩而过 |
| **小口稳吃 / 大口贪两份** | 短空档吃小口更稳；老师背身又遇上齐读，可以贪大口，但举手更久、嘴里更难清空 | **第二优先。** 两个相邻按区，仍然长按。若采用，目标单位改为「份」 |
| **视线扫过这一排** | 老师还面向全班，但刚看过你这一排。此刻抢先拿，还是等他彻底转过去？ | 数学课进阶。用头和视线的移动让路线可读，避免凭感觉乱抓 |
| **先撕袋，再慢慢吃** | 老师背身却很安静，手能动，袋子一撕就响；借齐读开袋后，短空档也能直接拿 | 包装型关卡。用原有长按，不额外加按钮；一局至少留两个可开袋的机会 |
| **借课堂里最响的一拍** | 齐读、翻卷子最响的那一瞬能藏住咔嚓。是抢这一拍快嚼，还是保守地慢慢嚼？ | 语文课进阶。看领读的手势也能预判，不要求开声音或每一口都踩点 |
| **点名必须空嘴** | 前一位被叫到，下一个轮到你。是赶紧咽，还是本来就别贪这一口？ | 单堂课的高潮。点名时只查能不能答到，别同时要求玩家做题或处理桌面 |
| **同桌帮忙打掩护** | 一局一次，让同桌翻开一叠试卷制造短暂声窗。现在用，还是留给最后一口？ | 先做可选道具。点同桌要有短前摇，能预判，不是紧急无敌键 |
| **吃完还要收包装** | 包装留桌面，下一口拿得快；老师走近时，要先收包装还是先咽掉嘴里那口？ | 自习课专属。首次巡逻把「看桌面」和「看脸」错开，给玩家选择顺序的余地 |
| **十秒课堂残局** | 开局已经含着半口、包装在桌上、老师还有两排。重复同一套事件，挑战能否把顺序排对 | 独立短挑战。复用现有规则，做出一个可快速重开的高压瞬间 |

### 先试哪三版

| 版本 | 只改什么 | 看什么 |
| --- | --- | --- |
| **A · 基线** | 现有数学课：按住、松手、回头扫视 | 玩家是不是只在背身时按住，几乎没有临场改动作 |
| **B · 差一点被抓** | 在同一套基础节奏里加入一次可预判的近查。可先截成十秒，从嘴里已有半口开始 | 玩家会不会因脚步提前咽下，或主动补最后一下快嚼？躲过之后能不能说出「刚才差点在哪」？ |
| **C · 贪不贪一大口** | 保留 B，只加小口与大口选择 | 玩家会不会短窗选小口、长窗选大口？如果总选同一种，优先调收益和风险 |

先做 A、B 的对照，尽量使用同样的食物、表现和课堂时间。若 B 只让人更容易输，先把预警和应对时间做清楚；若 B 能让人主动改动作、躲过去后马上想重开，再做 C。首版不把点名、传卷、收包装同时放进同一局。
